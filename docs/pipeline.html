From Chat History to Decision Heuristics

Decision Context Tracing Pipeline

How It Works

  1. 1Event Extraction — Raw AI agent logs (JSON) are flattened into a clean event stream. Each event contains timestamp, author, and message content including tool calls and reasoning.
  2. 2Reasoning Trace Derivation — Using DSPy + Gemini-3-Flash, we analyze events to extract the why behind agent decisions: patterns, reasoning logic, and outcomes.
  3. 3Pattern Synthesis — A multi-phase recursive synthesis identifies recurring patterns across sessions and generalizes them into principles, anti-patterns, and conditional rules.

The Result: Learned Pattern Library

The final catalog isn't a true ontology for now (no class hierarchy or relationships)—it's a decision heuristics catalog, the residue of successful coordination. It captures behavioral patterns that distinguish effective agent work from failure:

  • ◆ Holistic Context Gathering — Look before leaping
  • ◆ Environment-Aware Recovery — Fast pivoting when tools fail
  • ◆ Terminal-State Consistency — Preventing UI/UX hangs
  • ◆ Fidelity-Verification — Trust but verify outputs
